# ROF 3D Map Project

## Project Overview
ROF 3D Map Project is an immersive web experience built to showcase real-estate developments through an interactive 3D map and promotional landing page. Visitors are greeted by a full-screen hero slider that introduces the brand and can transition into a browser-based 3D map where they can explore buildings, neighborhoods, and amenity highlights. The project blends traditional web layout techniques with WebGL-powered rendering so that marketing teams can present large-scale master plans or city districts in an engaging, interactive format.

## Technologies and Tools Used
- **HTML5 & CSS3** for the static landing page, navigation layout, and responsive presentation across screen sizes. [`index.html`](index.html), [`css/custom.css`](css/custom.css)
- **JavaScript (ES Modules)** for page interactivity, slider animation, and viewport utilities. [`js/banner.js`](js/banner.js)
- **MapLibre GL JS 3.6+** for map rendering, terrain controls, and real-time camera interaction. [`assets/F1.js`](assets/F1.js), [`assets/map-4YEUKsWU.js`](assets/map-4YEUKsWU.js)
- **Three.js 0.160+** (with `GLTFLoader`) to load and render custom `.glb` models in sync with the map camera. [`assets/F2.js`](assets/F2.js), [`Euro_International_School.glb`](Euro_International_School.glb)
- **jQuery 2.x** for lightweight DOM manipulation and toggling UI states across the navigation and modals. [`map.html`](map.html), [`js/jquery-2.1.1.min.js`](js/jquery-2.1.1.min.js)
- **Vite 5** as the development server and bundler for module-based builds and hot reloading. [`package.json`](package.json), [`vite.config.js`](vite.config.js)
- **Node.js & npm** to manage dependencies, run the local dev server, and produce production builds.

## Features
- **Promotional landing page:** A branded home page with a looping banner slider and call-to-action button that directs users to the 3D map explorer. [`index.html`](index.html)
- **Interactive 3D map:** A MapLibre-powered base map enhanced with Three.js so that GLTF models (for example, Euro International School) appear in true 3D at geolocated coordinates. [`assets/map-4YEUKsWU.js`](assets/map-4YEUKsWU.js), [`Euro_International_School.glb`](Euro_International_School.glb)
- **Custom navigation and modals:** Desktop and mobile navigation menus, dropdowns, and modal dialogs that reveal project information or landmark details. [`map.html`](map.html), [`css/custom-responsive.css`](css/custom-responsive.css)
- **Compass and orientation controls:** An on-map compass widget visually tracks map bearing and can be extended to handle click-based reorientation. [`map.html`](map.html)
- **Fullscreen mode support:** A toggle button leverages the Fullscreen API to enter or exit immersive viewing with responsive icon states. [`map.html`](map.html)
- **Responsive layout:** CSS breakpoints and adaptive components ensure the experience remains usable on tablets and phones, including alternate hamburger menus and optimized compass sizing. [`css/custom.css`](css/custom.css), [`css/custom-responsive.css`](css/custom-responsive.css)
- **Multiple deployment contexts:** Additional map variants (e.g., `mapcasa.html`, `mosque.html`) can load alternative map configurations or branding without duplicating the core asset pipeline. [`mapcasa.html`](mapcasa.html), [`mosque.html`](mosque.html)

## Setup and Installation
1. **Install prerequisites**
   - Node.js 18 or later (required by Vite 5 and modern ESM tooling)
   - npm (bundled with Node.js)
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Run the development server**
   ```bash
   npm run start
   ```
   Vite will serve the project at the URL it prints to the console (default `http://localhost:5173`). Any edits to HTML, CSS, or module scripts trigger instant hot reloads.
4. **Create a production build** (optional)
   ```bash
   npm run build
   ```
   The optimized static files will be written to `dist/`. You can host this directory on any static file server or CDN.
5. **Preview the production bundle** (optional)
   ```bash
   npm run preview
   ```
   Vite will launch a local server that serves the contents of `dist/` so you can validate minified assets.

## Usage
1. **Landing page walkthrough**
   - Visit `http://localhost:5173/` while the dev server is running.
   - Observe the autoplay hero slider and use the “Explore Now” button to reach the interactive map.
2. **Exploring the 3D map**
   - Drag to rotate the view, scroll (or pinch) to zoom, and use the on-screen compass to monitor orientation.
   - Toggle fullscreen using the bottom-right button to enter a more immersive mode; exit fullscreen through the same control or with the ESC key.
   - Open the navigation items (“About Us”, “New Launch”, “Projects”) to reveal contextual content and image galleries.
3. **Switching between map variants**
   - Load `mapcasa.html` or `mosque.html` directly to view alternative map styles or datasets that reuse the same UI framework.
4. **Customizing models and layers**
   - Replace the sample GLB models in the repository (e.g., `Euro_International_School.glb`) or add new ones in the `models/` directory.
   - Update the map configuration in `assets/map-4YEUKsWU.js` to adjust base maps, camera positions, layer styling, or to inject additional Three.js scenes.
   - Modify styles in `css/custom.css` and `css/custom-responsive.css` to align with branding requirements or adapt to new UX flows.
5. **Deploying**
   - After running `npm run build`, upload the `dist/` output to your hosting provider. Ensure referenced assets such as images, GLB models, and fonts remain in their relative directories.

With these steps, designers, developers, and marketers can collaborate on delivering a high-impact, map-driven presentation that brings real-estate portfolios to life.
